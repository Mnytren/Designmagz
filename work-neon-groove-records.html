Personal Concept Project

Introduction

Neon Groove Records is a personal design exploration inspired by synthwave culture, retro-futuristic aesthetics and electronic music.

The project combines immersive UI design with custom digital artwork to create a music platform concept.

Role
UI Designer, Art Director
Tools
Figma, Photoshop
Project Type
Personal Concept

Creating the artwork

The artwork was built from multiple visual elements including space imagery, palm trees, lighting effects and a retro van. Each asset was individually adjusted, color-graded and integrated into the final composition to create a cohesive synthwave-inspired atmosphere.

Desktop Experience

The desktop experience was designed to balance immersive visuals with clear content hierarchy, allowing the artwork to remain the focal point of the interface.

Mobile Experience

The mobile experience preserves the same visual identity while adapting content and navigation for smaller screens.
