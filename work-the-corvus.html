The Corvus

Personal Digital
Art Project

Corvus is a personal concept artwork exploring digital compositing, atmospheric storytelling and sci-fi worldbuilding. Built from multiple visual elements and refined through color grading, lighting and visual effects, the project aims to create a cinematic and immersive futuristic scene.

Creating
the artwork

The artwork was built by combining multiple visual elements into a cohesive composition. Atmospheric effects, lighting and color grading were used to establish depth and mood.
